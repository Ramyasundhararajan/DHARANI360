Automate it (Windows Task Scheduler)

Once SMTP is saved, DHARANI 360 can email this digest automatically every morning without the portal needing to be open. In Windows: open Task Scheduler → Create Basic Task → name it "DHARANI 360 Digest" → trigger Daily at your preferred time → action Start a program → point it at send_digest.bat inside this folder.
